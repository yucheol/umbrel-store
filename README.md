# Yucheol Apps — 개인용 Umbrel 커뮤니티 앱 스토어

Umbrel 공식 스토어에 없는 앱을 정식 앱처럼 설치하기 위한 개인 스토어입니다. 앱을 추가할 때는 앱 폴더를 하나 더 만들어 같은 규칙으로 파일을 넣으면 됩니다.

## 구성

- `umbrel-app-store.yml` — 스토어 정보 (id: yucheol)
- 앱 폴더 (폴더 이름 = 매니페스트의 앱 id)
  - `umbrel-app.yml` — 앱 매니페스트
  - `docker-compose.yml` — 컨테이너 정의
  - `exports.sh` — (선택) Umbrel 시드에서 파생되는 앱별 환경변수
  - `hooks/pre-start` — (선택) 앱 시작 전 준비 스크립트
  - `assets/icon.png` — (선택) 앱 아이콘

앱 id 규칙: 스토어 id + 앱 이름 (예: `yucheol-komga`). 폴더 이름과 매니페스트의 id가 반드시 같아야 합니다.

## 등록 방법

1. 이 repo를 GitHub에 올립니다 (구조 유지).
2. Umbrel 앱스토어 우측 상단 ⋯ 메뉴 → Community App Stores → repo 주소를 붙여넣고 추가합니다 (스토어 등록은 한 번만).
3. 스토어 목록에 앱이 뜨면 일반 앱처럼 설치합니다. Umbrel이 repo를 약 5분 간격으로 동기화하므로, 파일을 바꾼 뒤 반영까지 몇 분 걸릴 수 있습니다.

## 앱별 메모

### Komga

- DB·설정은 Umbrel 로컬 앱 저장소(`/config`)에 보관됩니다. 네트워크 공유에는 두지 않습니다 (Komga 공식 문서의 요구사항).
- 설치 후 앱 설정에서 라이브러리 폴더 접근을 허용합니다. Synology 공유 안의 만화 폴더를 선택하면 Komga 안에서 `/data`로 보입니다 (읽기 전용이라 원본 파일이 수정되지 않습니다).
- 웹 화면(umbrel.local:25600)에서 첫 계정을 만들고, 라이브러리를 추가할 때 `/data` 아래 폴더를 지정합니다.

### 2FAuth

- 데이터(DB·아이콘·로그)는 Umbrel 로컬 앱 저장소(`/2fauth`)에 보관됩니다.
- 처음 만든 계정이 관리자가 됩니다.
- 암호화 키(APP_KEY)는 이 repo에 들어 있지 않습니다. `exports.sh`가 Umbrel 자체 시드에서 파생시키므로 이 Umbrel에서만 유효하고, 재시작·업데이트해도 유지됩니다.
- 기존 2FAuth에서 옮길 때는 DB 파일을 복사하지 말고, 기존 인스턴스에서 내보낸(Export) 파일을 새 인스턴스에서 가져오기(Import) 합니다. 두 인스턴스의 APP_KEY가 서로 다르기 때문입니다.
- Umbrel 로그인 관문을 그대로 두었습니다 (앱 프록시 인증 유지).

## 패키징 메모 (새 앱을 추가할 때)

- 매니페스트에 `gallery: []`가 없으면 Umbrel 앱 페이지가 열리지 않습니다.
- Umbrel이 만드는 앱 데이터 폴더는 root 소유입니다. root가 아닌 사용자(예: 1000:1000)로 실행되는 앱은 DB 파일을 만들지 못할 수 있으니, 필요하면 `hooks/pre-start`에서 데이터 폴더의 소유권을 앱 사용자로 넘깁니다 (2FAuth가 이 방식).
- 비밀값(암호화 키·비밀번호)은 공개 repo에 직접 쓰지 말고, `exports.sh`에서 `derive_entropy`로 파생시켜 씁니다.
